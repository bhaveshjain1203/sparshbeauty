# Sparsh Beauty Studio & Academy (`sparshbeauty.com`)

Official multi-page website for **Shikha Jain** — Makeup Artist, Hairstylist & Educator at **Sparsh Beauty Studio & Academy**, Boliya, District Mandsaur (Madhya Pradesh).

## Pages Included
- `index.html` — Home & Editorial Overview
- `portfolio.html` — Filterable Lookbook (Rajwadi & Rajputi Bridal, HD/Reception, Permanent Hair, Model Shoots & Seminars) with Lightbox
- `academy.html` — 25-Day Pro Makeup, Hair & Draping Diploma + Bilingual (English / हिंदी) Brochure Modal
- `academy-short-courses.html` — Short Certificate Courses (Self-Grooming, Bridal & Rajwadi Intensive, Permanent Hair Specialist)
- `prices.html` — Tabbed Packages & Services Rate Guide
- `studio.html` — Boliya Studio Standards & Permanent Hair Straightening Lab
- `about.html` — About Shikha Jain, Collaborations, Beauty Seminars & Award Events
- `contact.html` — Booking & Academy Enquiry Form, Studio Address & Map Link

## Quick Customization
1. **Phone, WhatsApp, Email & Batch Dates**: Edit [`assets/js/site-config.js`](assets/js/site-config.js) once — every page header, footer, booking modal, and WhatsApp button updates automatically.
2. **Real Photos**: Replace the editorial SVG artworks in `assets/images/` with Shikha Jain's actual bridal, hair transformation, and seminar photography (`.jpg` / `.webp`) and update the corresponding `src` paths.
3. **Deploy**: Zero build step required — upload the root folder directly to any static host (Cloudflare Pages, Netlify, GitHub Pages, Vercel, or cPanel for `sparshbeauty.com`).
